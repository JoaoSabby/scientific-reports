# Springer Nature Quarto extension

This directory mirrors the Quarto extension distributed in the public repository:

https://github.com/christopherkenny/nature

The extension adapts the Springer Nature LaTeX journal template for Quarto and provides the `nature-pdf` output format together with the bundled Springer Nature BibTeX styles.

The scientific reports in this repository are published primarily as HTML. HTML citation formatting is therefore handled by `styles/nature.csl`. The extension is retained to preserve compatibility with the Springer Nature Quarto model and to support future PDF rendering when required.

Upstream documentation states that the underlying Springer Nature journal article template is licensed under the LaTeX Project Public License 1.3c.
